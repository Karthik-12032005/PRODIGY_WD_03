# 🎮 Tic-Tac-Toe Web Application

A modern and responsive Tic-Tac-Toe Web Application built using HTML, CSS, and JavaScript.

## 🚀 Features

* Two Player Gameplay
* Win & Draw Detection
* Restart Game Functionality
* Interactive User Interface
* Responsive Design
* Smooth Hover Animations

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript
